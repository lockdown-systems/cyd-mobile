# Finish an export around a file that moved

Cyd Mobile treats a preserved file that changes after a Cyd Bluesky archive export has hashed it as an unavailable asset and rebuilds the archive around it, rather than failing the export. Packaging is the last chance to catch a file the point-in-time inventory and the hashing pass both accepted, and a resumed export would otherwise reread the same stale digest and fail identically on every launch. Each attempt demotes at least one asset, so an export always reaches an honest incomplete archive instead of a permanent failure, and the checkpoint records the demotion so it survives a restart. Each demotion costs a full rebuild of the interchange database and the archive, which is accepted because a file moving after it has been hashed is rare and the alternative is an account that can never export.

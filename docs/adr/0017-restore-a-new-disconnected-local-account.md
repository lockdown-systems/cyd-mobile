# Restore an archive into a new disconnected Bluesky local account

Cyd Mobile commits a prepared Cyd Bluesky archive for an identity it does not already hold by creating one new, disconnected Bluesky local account, writing that account's private database in a single transaction, and copying each packaged asset into the account's own media storage under its digest, so one file is stored per unique image or video and browsing needs no network. The Bluesky archive's local-account UUID is adopted when free and remapped with a report when another Bluesky identity holds it, while an archive whose DID this installation already knows is refused here and belongs to the recovery merge instead. An asset the Bluesky archive marked unavailable, or that will not copy, becomes a failed download that keeps its source URL rather than a failed restore, and the Bluesky archive's own completeness is recorded on the restored account instead of being recomputed, so an incomplete Cyd Bluesky archive still restores every record it does carry.

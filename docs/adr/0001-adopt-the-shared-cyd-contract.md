# Adopt the shared Cyd contract

Cyd Mobile adopts the cross-client Cyd Bluesky archive specification, Bluesky version history, canonical fixtures, and compatibility expectations owned by the `cyd` repository rather than maintaining a duplicate normative contract. Other social platforms have independent archive contracts and version histories. Mobile records only its implementation-specific decisions locally, so shared behavior has one source of truth while mobile constraints remain discoverable in this repository.

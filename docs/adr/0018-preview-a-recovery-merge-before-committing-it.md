# Preview a recovery merge before committing it

Cyd Mobile splits a Bluesky archive merge into a preview that reads the prepared Cyd Bluesky archive and works out every row it would write, and a commit that carries that preview out, so nobody imports an archive without being told what it would do. The preview counts what it would add, a line for each kind of Bluesky saved record in the words Bluesky browse uses for them, rather than naming each record: Mobile has no Bluesky local deletion, so a Bluesky saved record missing from a Bluesky local account is one the account never had rather than one somebody chose to be rid of, and there is nothing for them to recognise in a list. Naming each record becomes worth its screen again if Mobile ever lets somebody remove Bluesky saved data without removing it from Bluesky; the plan already separates the records it would add from the ones it would enrich, so that would be a presentation change over rows it has in hand. The commit re-reads the Bluesky local account instead of trusting the preview's copy, so work that ran in between is merged rather than overwritten, and committing the same Cyd Bluesky archive again writes nothing.
